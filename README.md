# Sistema Lar da Bênção

Pasta do sistema com histórico Git. Versão atual: **215 — Visual acolhedor**, publicada em 14/09/2026. Organização desta cópia: 15/09/2026.

## Arquivos principais

- `dist/index.html`: sistema completo, com telas para computador, celular e tablet.
- `dist/MANUAL_ILUSTRADO_LAR_BENCAO_v213.html`: manual ilustrado disponível.
- `dist/MANUAL_ILUSTRADO_LAR_BENCAO_v213.pdf`: manual em PDF.
- `dist/MANUAL_ILUSTRADO_LAR_BENCAO_v212.html`: manual anterior preservado por compatibilidade.
- `theme-215/`: arquivos do tema visual e roteiro de verificação.
- `.openai/hosting.json`: identificação do site de teste existente.

O manual disponível é da versão 213; a ajuda do sistema inclui orientações acrescentadas nas versões posteriores.

## Como abrir

Abra `dist/index.html` no navegador deste computador. No celular ou tablet, utilize o site de teste:

https://lar-da-bencao-teste-celular.trick8764.chatgpt.site/

O acesso ao site mantém as permissões configuradas na hospedagem.

## O que está salvo no Git

Os arquivos do programa, os manuais e o histórico de alterações. Os cadastros e anexos preenchidos no navegador não são incluídos automaticamente no Git. Para guardá-los, utilize o recurso de backup completo do sistema.

Esta versão utiliza armazenamento local no navegador. Aparelhos ou navegadores diferentes ainda não compartilham uma base de dados central.

## Desenvolvimento

O HTML em `dist/index.html` funciona de forma independente dos scripts de construção. O gerador em `theme-215/build.py` depende da versão 214 preservada no diretório de desenvolvimento original; não é necessário executá-lo para usar esta cópia.

O histórico foi preservado a partir do repositório do site. Nenhuma nova publicação ou alteração de permissões é realizada apenas ao salvar esta pasta.
